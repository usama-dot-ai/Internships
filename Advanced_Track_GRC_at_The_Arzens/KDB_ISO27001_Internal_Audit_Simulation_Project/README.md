# KDB ISO 27001 Internal Audit Simulation Project

## Project Overview

This repository contains an **ISO/IEC 27001:2022 Internal Audit Simulation Project** developed as part of the **Advanced Track GRC internship at The Arzens**.

The project simulates an end-to-end internal audit for **Kohsar Digital Bank (KDB)** and documents the audit process across four sequential phases, covering audit planning and scope definition, checklist preparation, evidence and findings assessment, and final reporting with corrective action recommendations.

## Phases and Deliverables

### Phase 1 — Audit Planning and Scope

This phase establishes the foundation for the internal audit simulation, including the audit planning approach, scope, objectives, criteria, and other relevant planning elements.

**Directory:**

```text
Phase_1_Audit_Planning_and_Scope/
```

### Phase 2 — Checklist Preparation

This phase focuses on developing the internal audit checklist used to evaluate the applicable ISO/IEC 27001:2022 requirements and selected controls during the simulated audit.

**Directory:**

```text
Phase_2_Checklist_Preparation/
```

### Phase 3 — Evidence Log and Findings

This phase documents the evidence considered during the simulated audit and records the findings identified through the assessment of the selected audit criteria and controls.

**Directory:**

```text
Phase_3_Evidence_Log_and_Findings/
```

### Phase 4 — Corrective Actions and Final Report

This phase consolidates the results of the simulated audit into formal reporting outputs and provides corrective action recommendations addressing the identified findings.

**Directory:**

```text
Phase_4_Corrective_Actions_and_Final_Report/
```
